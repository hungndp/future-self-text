One funny text message your future self sends you, under 200 characters. A warning about a car choice that inverts itself on the last word: the "safe" car kills you too, only slower.

## Run it

```sh
python3 main.py
```

Writes the message to `/output/entry.txt` (or `$ENTRY_OUTPUT`) with no trailing newline.
